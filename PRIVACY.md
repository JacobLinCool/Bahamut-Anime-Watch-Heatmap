# Privacy Policy

Last updated: 2026-04-30

Bahamut Anime Watch Heatmap is a browser extension that adds a yearly watch history heatmap to Bahamut Anime (`ani.gamer.com.tw`).

## Data Access

The extension runs only on `https://ani.gamer.com.tw/*`. On Bahamut Anime watch history pages, it reads watch history information already present in the page DOM, including watch dates, watch times, anime titles, and episode labels. This data is used only to render the heatmap and tooltip inside the same page.

The extension stores one local preference: the selected day boundary mode (`24H` or `30H`). This preference is saved in the browser's local storage for the site.

## Data Collection and Sharing

The extension does not collect, transmit, sell, share, or remotely store user data.

The extension does not send watch history, page content, browsing history, identifiers, analytics events, or usage data to the developer or to any third party.

## Remote Code

The extension does not load or execute remote JavaScript, WebAssembly, or other remotely hosted executable code. All extension code is included in the packaged extension.

## Permissions

The extension needs access to `https://ani.gamer.com.tw/*` so its content script can run on Bahamut Anime pages, read the watch history DOM, and insert the heatmap UI.
